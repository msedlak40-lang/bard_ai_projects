SECTION 1.1: PT NOTE PROCESSING
----------------------------------------

Q1. How many PT notes do you read per week?
   CONSENSUS: All 5 coaches read 40+ notes per week
   KEY INSIGHT: Multiple coaches clarified this is actually 40+ notes per DAY
   - Coach 1: '40+ notes/day, especially for midpoint and outlier cases'
   - Coach 3: 'I probably read 40+ a day'
   - Coach 4: '150+ notes/week (~2 notes per case, 15-20 cases/day)'
   - Coach 5: '40+/day'

Q2. How long to read and extract key information from one PT note?
   RANGE: 5-15 minutes depending on note type and case complexity
   - Coach 1: 5-10 min (more for IE/progress notes, less for daily notes)
   - Coach 2: 5-10 min
   - Coach 3: 10-15 min (varies by case stage and recency of review)
   - Coach 4: IE: 5-7 min, Other: 3-5 min
   - Coach 5: 5-15 min (depends on note type and case history)

Q3. How long to summarize an entire case for remediation/case write-up?
   RANGE: 15-30+ minutes depending on case complexity
   - Coach 1: 30+ min (longer for complex/multiple cases, includes therapist outreach)
   - Coach 2: 15-20 min (remediation), 30+ min (case write-up/investigation)
   - Coach 3: 10-15 min (recent), 20-30 min (not recently reviewed)
   - Coach 4: Has not done official case review yet; relies on QA notes
   - Coach 5: 30+ min (total time across multiple case reviews)

Q4. What format are the PT notes you receive?
   CONSENSUS: Mix of both structured and narrative formats
   CHALLENGES:
   - Handwritten notes (difficult to read, often missing key info)
   - Non-bNOTES clinics send subpar notes missing key information
   - Standard SOAP notes: narrative S/A/P, objective measures or therex grid for O

Q4b. What information do you extract from each PT note?
   ALL COACHES EXTRACT:
   - Range of motion (ROM) changes
   - Pain level / pain trend
   - Exercise progression
   - Exercise compliance
   - Functional improvements (especially work-related)
   - Patient attitude / motivation
   - Red flags
   ADDITIONAL ITEMS MENTIONED:
   - Attendance compliance
   - Strength changes (from progress notes)
   - Mechanism of Injury (from Initial Eval only)
   - Work status, PDC level, surgery details, comorbidities, goals
   - Therapist assessments/plans
   NOTE: Coach 1 clarified: 'Discouragement is not a red flag, neither is pain increase.'
         Red flags include changes in medical status or health concerns.

Q5. After reading a PT note, what do you do?
   PRIMARY ACTION: Record information in bNOTES (all coaches)
   SECONDARY ACTIONS (as warranted):
   - Message the patient
   - Email stakeholders
   - Task internal Bard team member
   - Flag for later action / set follow-up
   - Call or email treating therapist
   - Check HealthCloud for updates
   KEY INSIGHT: Actions depend on specific case needs, not automatic workflow

Q6. How many days after the PT visit do you typically read the note?
   CONSENSUS: Varies widely
   REASONS:
   - Notes don't always arrive in timely manner
   - Depends on when clinic submits notes
   - Most recent note reviewed is typically nearly a business week old
   - Review timing based on audit list priority
   - Coach 5: 'This question is not valid for how our processes work'

================================================================================
KEY THEMES & AUTOMATION OPPORTUNITIES
================================================================================

1. VOLUME & TIME BURDEN
   - Coaches read 40+ PT notes per DAY (not week as questionnaire assumed)
   - 5-15 minutes per note = 3-10+ hours/day on note reading alone
   - 30-90+ minutes/day on patient messaging

2. NON-CLINICAL MESSAGING (HIGH AUTOMATION POTENTIAL)
   - UNANIMOUS: Most patient messages don't require clinical expertise
   - Admin issues dominate: scheduling, payments, transportation, authorization
   - Coaches want to focus on outlier/midpoint cases requiring clinical judgment

3. AUTOMATED CHECK-IN SYSTEM (SUGGESTED BY COACHES)
   - Initial automated check-in after IE
   - Biweekly automated check-ins for first month (3 total)
   - Manual intervention only when warranted by patient response

4. NOTE QUALITY ISSUES
   - Non-bNOTES clinics send subpar notes
   - Handwritten notes are difficult to read
   - Missing flowsheets/exercise details
   - Inconsistent note arrival timing

5. INFORMATION EXTRACTION STANDARDIZATION
   - Coaches extract similar information (ROM, pain, compliance, function)
   - Work-related functional improvements are critical
   - Red flag definitions need clarification (pain increase alone isn't a red flag)

6. WORKFLOW INTEGRATION
   - Note reading and messaging are integrated, not separate activities
   - Actions depend on specific case needs
   - Coaches frequently check HealthCloud for updates during review


================================================================================
RECOMMENDATIONS FOR AUTOMATION
================================================================================

HIGH PRIORITY:
1. Automated patient check-in system
   - Initial welcome/check-in after IE
   - Biweekly automated check-ins for first month
   - Route non-clinical responses to admin team

2. PT Note summarization tool
   - Extract key clinical data points automatically
   - Flag notes requiring coach attention
   - Highlight changes from previous notes

3. Admin issue routing
   - Auto-detect scheduling, payment, transportation issues in messages
   - Route to appropriate admin team
   - Only escalate clinical issues to coaches

MEDIUM PRIORITY:
4. Note quality alerts
   - Flag subpar notes from non-bNOTES clinics
   - Identify missing required information

5. Case prioritization
   - Highlight midpoint and outlier cases
   - Reduce time spent on early-stage, low-risk cases
